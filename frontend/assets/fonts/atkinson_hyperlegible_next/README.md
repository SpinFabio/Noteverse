# Atkinson Hyperlegible Next

Bundled static Regular (400) and Bold (700) fonts from the
[official font repository](https://github.com/googlefonts/atkinson-hyperlegible-next/tree/main/fonts/ttf).

The fonts are distributed under the SIL Open Font License 1.1; see `OFL.txt`.
The app loads them locally through `pubspec.yaml`. Typography is configured in
`lib/theme/noteverse_typography.dart`.
