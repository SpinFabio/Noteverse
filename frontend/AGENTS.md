# Frontend rules

## Typography

- Use Atkinson Hyperlegible Next as the application-wide font, including text
  drawn on graph canvases. Configure typography centrally in `lib/theme/`.
- Use bold (`FontWeight.w700`) for all titles and headings, including Material
  `title`, `headline`, and `display` styles. Consume these styles from the theme.
- Follow the additional design-system rules in `lib/theme/AGENTS.md` when
  changing the theme.
